About

Keeping Wikidata verifiable

A small tool for a big job: making sure the sources behind Wikidata statements still exist.

The Wikidata Reference Validator checks the external references on a Wikidata item to see whether their links can still be reached. Statements on Wikidata are only as trustworthy as the sources behind them. When a source disappears, readers can no longer verify how we know what we know.

What it does

  • Searches Wikidata items with autocomplete. You can also type a QID such as Q42 directly.
  • Collects every reference URL on the item's statements and checks each unique URL once, concurrently.
  • Marks each reference as alive or unreachable, and looks up the latest Wayback Machine snapshot for unreachable ones.
  • Groups results by statement and by type of source, so patterns stand out (for example, a news site that has gone offline).
  • Links straight to the statement on Wikidata so you can fix it.

The grouping is a simple heuristic based on known domains and top-level domains such as .gov and .edu. It gives an overview; it doesn't judge how reliable a source is.

Limitations

  • Some websites block automated requests or time out. A link marked unreachable is a prompt to review it, not proof that it is gone.
  • Pages that still return a successful response but no longer contain the cited content can't be detected.
  • Only URL references are checked. Identifiers such as VIAF or GND IDs are not.

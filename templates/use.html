Guide

How to use

Find and fix dead references on Wikidata in a few steps.

  1. Find an item. Start typing a name on the home page and choose an item with the mouse or with ↑ ↓ and Enter. You can also paste a QID such as Q42. Press / anywhere to jump to the search box.
  2. Let it check. The tool requests every reference URL on the item's statements. Items with many references can take up to a minute.
  3. Read the summary. The summary strip shows how many references are reachable, and the contents list shows how many unreachable references each statement has.
  4. Narrow it down. Filter by status (Unreachable, Archived, Alive), by type of source (news, government, academic…), or by typing part of a URL or statement.
  5. Fix it on Wikidata. Use the button next to a reference to open that statement on Wikidata, then update the reference or add the archived copy.
  6. Share it. Every result has its own link (for example /?item=Q42), so you can send a check to other editors.

What the results mean

  • Alive: the server responded. Pages behind a login or that block bots (HTTP 401/403/429) also count as alive.
  • Unreachable: the server returned an error (such as 404) or didn't respond in time.
  • Archived: a Wayback Machine snapshot exists and can replace or supplement the dead link.

Example
